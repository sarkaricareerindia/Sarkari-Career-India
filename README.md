# Sarkari Career India

A responsive government-job portal homepage inspired by the supplied reference design.

## Files
- `index.html` — page structure
- `style.css` — responsive styling
- `script.js` — mobile menu and search interactions

## GitHub Pages
Upload the three files to the repository root. Then open:
Settings → Pages → Deploy from a branch → select `main` and `/ (root)` → Save.

Replace the demo job links/text with your real links and updates.
